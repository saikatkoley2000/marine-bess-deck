# VFCPL Marine BESS — ABS ESS-LiBATTERY & IRS Compliance Presentation

Interactive presentation deck and compliance engineering package for the **VFCPL 250 kW / 520 kWh Marine Lithium-ion Battery Energy Storage System (BESS)** with dielectric liquid immersion cooling (`Project SAMUDRA`).

Dual-class certification alignment:
- **ABS**: *Requirements for Use of Lithium-ion Batteries in the Marine and Offshore Industries* (Dec 2025) — `ESS-LiBATTERY` notation.
- **IRS**: *Approval of Lithium-ion Battery Systems* (Mar 2026, Rev.1) & *Guidelines for Battery Powered Vessels* (Rev.02).

## 🛠 Deployment

### Deploy to Vercel
1. Push this repository to your GitHub account.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the GitHub repository and click **Deploy**.

Alternatively, run Vercel CLI:
```bash
npx vercel
```
